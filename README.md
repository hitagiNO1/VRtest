使用版本 Unity `6000.0.80f1` 

## 桌面模式

1. 按「選擇道具」，右邊會展開清單。再按一次可以收起來。
2. 按住某一格，拖到場景裡。
3. 拖曳時會出現道具預覽和黃色指引線。預覽是清楚的、而且有黃線，代表這個位置可以放，放開滑鼠就會放在地上。
4. 預覽變半透明、沒有黃線，代表現在不能放（例如滑鼠還在 UI 上，或沒有對到地面）。這時放開就會取消。
5. 放好之後，用滑鼠左鍵點那個道具，旁邊會出現刪除選單，按刪除就能清掉。

## VR 模式

1. 用射線點「選擇道具」，打開清單。
2. 點清單裡的某一列。清單會收起來，道具預覽會跟著射線移動。
3. 對準地面，再扣一次扳機，道具就會放下。黃線和預覽的意思跟桌面模式相同：看得到黃線就能放，變淡就是這次會取消。
4. 之後對準場上的道具再扣一次，就會出現刪除選單。
5. 用射線點刪除即可。

### 沒有頭顯時（模擬器）
進到 VR 場景後，畫面上會出現 XR Device Simulator，用滑鼠控制手把的方向。
- 空白鍵：移動右手把
- 滑鼠右鍵按住：移動頭部視角
- 滑鼠左鍵：扳機
- `G`：握把
